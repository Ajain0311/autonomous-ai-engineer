# Autonomous AI Software Engineer (Antigravity V2)

Antigravity V2 is a fully autonomous single-engineer software pipeline designed to continuously build, verify, maintain, and iterate on **one single production-grade SaaS application** over a long-term roadmap (6–12 months). It acts as a miniature, self-correcting software company that executes daily task planning, code generation, build verification, and deployment.

---

## 🚀 Vision & Philosophy
Rather than generating disposable, one-off toy apps, Antigravity V2 focuses on constructing a highly commercial, scalable SaaS product from scratch. 
* **Zero Paid Services:** Utilizes free APIs and serverless infrastructure (Supabase, Render, Netlify/Vercel) for maximum efficiency.
* **Disciplined Token Usage:** Context-aware prompts feed only the relevant module codebase files to the LLM to prevent context bloat.
* **Auto-Repair Loop:** If a task generates code that fails Quality Gates (compilation, bundling, or linting), a specialized debugging agent automatically attempts up to 3 repair passes to fix the syntax or logic errors before committing.
* **Steerable Control:** A beautiful in-repo management dashboard allows users to pause the runner, re-order milestones, view real-time log outputs, perform git operations, or trigger a full archiving reset ("Start From Scratch").

---

## 🛠️ Tech Stack & Architecture
The target application generated by the pipeline conforms to a modern production stack:
* **Frontend:** React 18, TypeScript, Vite, Tailwind CSS, React Router v6, Zustand state management.
* **Backend:** Node.js, Express (REST API layers).
* **Database:** Supabase (PostgreSQL with RLS policy bindings).
* **Deployment:** Render (Backend API), Netlify or Vercel (Frontend SPA).

## ⚙️ Multi-Provider LLM Client
Antigravity V2 handles failovers and key rotation out-of-the-box. When a rate limit (`429`), server error (`5xx`), or timeout occurs, the runner automatically moves down the priority ladder:

1. **Google Gemini** (2.0 Flash / 2.0 Flash-Lite / Gemma 3)
2. **Groq** (Llama 3.3 70B / Llama 3.1 8B)
3. **OpenRouter** (Free Models: Ling, Laguna, North Mini Code)
4. **Together AI** (Llama 3 8B)
5. **GitHub Models** (GPT-4o, Llama 3.1)
6. **Hugging Face** (Llama 3.2, Gemma 2)
7. **SambaNova** (Llama 3.3 70B, Llama 3.1 405B)
8. **Mistral AI** (Open Mistral)
9. **Cohere** (Command R+)
10. **Kilo AI** (Llama 3.1 8B, GPT-4o Mini)

## 📊 Single Source of Truth (`project_state.yaml`)
To prevent token-expensive context reconstruction, the entire software company state is tracked inside a single master tracking database file: [**`automation/project_state.yaml`**](file:///D:/Projects/daily-code/automation/project_state.yaml).
It maintains the product's vision, DB schema design, folder structure blueprints, milestones sequence, a backlog of hundreds of upcoming tasks, audit logs of all commits/actions, retry history, and lifecycle token expenditure counters.

Every run: **Reads state → Selects next task → Wires code changes → Quality gate compile → Git commit & push → Appends state trail.**

## 🖥️ Management Dashboard
A built-in interactive dashboard is served locally via a FastAPI web server in [**`dashboard/server.py`**](file:///D:/Projects/daily-code/dashboard/server.py).

### Run Dashboard Locally:
1. Run the FastAPI development server:
   ```bash
   uvicorn dashboard.server:app --reload --port 8000
   ```
2. Open [**`http://localhost:8000`**](http://localhost:8000) in your web browser.

### Key Capabilities:
* **Interactive Timeline:** Monitor milestones progress, completed details, and files modified.
* **Full Git UI Control:** Direct repository checkout, status monitoring, diff previewing, staging, committing, pulling, and pushing.
* **Start From Scratch (Destructive Reset):**
  1. Branches/Archives the current workspace code to `archive/<project-name>-<timestamp>`.
  2. Wipes generated code directories from `main`.
  3. Resets `project_state.yaml` milestones backlog.
  4. Triggers the upfront candidate scraper research and plan scoring on the next pipeline run.
